# GitHub Pages 設定教學（讓 IG、LINE 內建瀏覽器也能打開）

Apps Script 網頁在 IG／LINE 裡會變空白，所以把網頁放到 GitHub Pages（免費），
排盤與存資料仍然由你的 Apps Script ＋ 試算表處理。

## 第 1 步：更新 Apps Script（新增給外部網頁用的 API）
1. 打開「緣來Ru's 流月運勢」Apps Script 專案。
2. 重貼 `google-apps-script` 資料夾裡的 **Code.gs** 和 **Index.html**（Ctrl+A 刪掉 → 貼上）。
3. 存檔 → 管理部署作業 → ✏ → 「新版本」→ 部署。

## 第 2 步：建立 GitHub 專案（約 5 分鐘）
1. 到 https://github.com 註冊並登入（已有帳號就直接登入）。
2. 右上角「＋」→ **New repository**
   - Repository name：`fortune`
   - 選 **Public**（免費帳號的 GitHub Pages 需要公開；裡面只有網頁，沒有客人資料）
   - 按 **Create repository**
3. 點 **uploading an existing file**，把 `github-pages` 資料夾裡的 **index.html** 拖進去 → **Commit changes**。

## 第 3 步：開啟 GitHub Pages
1. 在專案頁面上方點 **Settings**（齒輪）。
2. 左邊選 **Pages**。
3. 「Build and deployment」→ Source 選 **Deploy from a branch**
   → Branch 選 **main**、資料夾 **/(root)** → 按 **Save**。
4. 等 1–2 分鐘重新整理，上方會出現網址：
   `https://你的帳號.github.io/fortune/`

## 第 4 步：使用
- IG 限動、IG 簡介、LINE 都用這個 github.io 網址。
- 舊的 script.google.com 網址也還能用（電腦瀏覽器正常）。

## 之後要修改網頁
- 改到 **Index.html 的內容**時，兩邊都要更新：
  1. Apps Script：重貼 Index.html → 存檔 → 管理部署作業 → ✏ → 「新版本」→ 部署
  2. GitHub：專案裡點 index.html → 右上 ✏ 或重新上傳 → Commit changes（約 1 分鐘生效）
- 只改 Code.gs／BaziCore.gs（排盤邏輯）時，只要更新 Apps Script。
